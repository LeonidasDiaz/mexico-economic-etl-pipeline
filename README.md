<a name="english"></a>
## English

### Overview
Automated ETL data pipeline extracting, transforming, and loading Mexico's macroeconomic indicators via official APIs using Python (Pandas) and SQL.

### Architecture & Tech Stack
* Language: Python 3.x
* Data Processing: Pandas, NumPy
* Database: SQLite / PostgreSQL, SQLAlchemy
* Version Control: Git, GitHub
* Environment Management: python-dotenv

### Project Status
In Development: Setting up core modules for API connection and extraction.
